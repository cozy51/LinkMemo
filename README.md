# LinkMemo - Chrome / Edge 仕事スタート

仕事で使うWebページをグループに登録し、Google ChromeまたはMicrosoft Edgeのツールバーからまとめてタブで開ける拡張機能です。同じ拡張機能フォルダーを両方のブラウザーで利用できます。

## 主な機能

- グループ単位、または全グループのリンクをまとめて開く
- 現在表示中のタブをポップアップから素早く登録
- クイック追加で前回選んだグループを記憶
- グループ／リンクの追加・編集・削除・並べ替え
- 用途別の30種類のグループアイコンと8種類の背景色
- 編集画面でグループとリンク、移動・編集・削除操作を色分け
- グループの折りたたみ状態を保存
- 登録内容のJSONバックアップと復元（インポート前に件数と日時を比較）
- Supabaseによるクラウド同期と、上書き前の内容を残すクラウド履歴
- データはブラウザー内のローカルストレージに保存（クラウド同期は任意）

## Google Chromeへのインストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダー（`LinkMemo`）を選択する
5. ツールバーの拡張機能メニューからLinkMemoを固定する

## Microsoft Edgeへのインストール

1. Edgeで `edge://extensions/` を開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押す
4. このフォルダー（`LinkMemo`）を選択する
5. ツールバーの拡張機能メニューからLinkMemoをピン留めする

## ブラウザー間のデータについて

登録内容は各ブラウザーのローカルストレージに保存されます。クラウド同期を設定していない場合、ChromeとEdgeの登録内容は自動同期されないため、同じ内容を使うには編集画面の「エクスポート」でバックアップし、もう一方のブラウザーで「インポート」してください。

複数のPCで常に同じ内容を使いたい場合は、下記のクラウド同期（Supabase）を設定してください。

## 使い方

1. LinkMemoのアイコンを押し、右上の歯車から編集画面を開く
2. グループとリンクを登録する
3. 仕事開始時に「すべてのタブを開く」または各グループの「まとめて開く」を押す

`http://` または `https://` のWebページを登録できます。登録データは外部サーバーへ送信されません。

拡張機能を読み込む前に見た目だけ確認したい場合は、`popup.html` または `options.html` をブラウザーで直接開くとサンプルデータ付きのプレビューになります。拡張機能として動作するときは、プレビュー用データは使用されません。

## クラウド同期とバックアップ（Supabase）

TodoMemo・Prompt Memoと同じ仕組みで、Supabaseを正本、`chrome.storage.local` をその手元のコピーとして扱います。ログインしていれば、追加・編集・削除のたびに自動でクラウドへ保存され、**上書きされる直前の内容は必ず履歴として残ります**。

### 準備

1. Supabaseでストレージのバケット（既定は TodoMemo と同じ `todo-backups`）を用意し、ログインするユーザーが自分のフォルダー（`{ユーザーID}/`）を読み書きできるポリシーを設定する
2. 編集画面の右上「クラウド設定」に、プロジェクトURL・anonキー・バケット名を入力して保存する
3. 「ログイン」にSupabaseのメールアドレスとパスワードを入力する

接続先が `https://*.supabase.co` 以外（独自ドメイン）の場合は、`manifest.json` の `host_permissions` にそのドメインを追加してください。

### 保存される場所

TodoMemoと同じバケットを共有できるよう、ファイル名にアプリ名が入ります。

- `{ユーザーID}/LinkMemo-latest.json`：クラウド上の最新の全グループ・全リンク
- `{ユーザーID}/LinkMemo-history/`：上書きされる直前の内容（履歴）

### 履歴の残り方と戻し方

- クラウドが上書きされるたびに、上書き前の内容を1件ずつ保管します
- 直近30件はすべて残し、それより古いものは1日1件で最大30日分を残します
- 「クラウド履歴」から、件数と日時を見て任意の時点に戻せます
- 戻す操作も「新しい版」として記録するため、他のPCも安全に追従します

### 古いデータで上書きしないためのしくみ

- クラウドの版（リビジョン）を基準に更新するため、古いPCが新しい内容を黙って上書きすることはありません
- 食い違いが起きたときは、**クラウドとこのPCの「最終更新」「グループ数」「リンク数」「ドメイン数」を並べて比較**し、増減付きで表示します
- このPCの内容がクラウドより**古い**、または**件数が大きく減る**場合は強い警告を出し、確認のチェックを入れるまで「このPCの内容でクラウドを上書き」を押せません
- リンクが半分以上減る変更や、リンクが1件も無くなる変更（ブラウザーデータの削除や誤操作など）は、確認するまでクラウドへ反映しません
- 選ばなかった方の内容もクラウド履歴へ退避するため、どちらを選んでも元に戻せます
- ログアウト中の変更はこのPCだけに保存され、次回ログイン時に上記の手順で照合されます
- ポップアップは同期状態の表示と自動送信のみを行い、食い違いが起きたときは編集画面へ誘導します

### インポート前の確認

全件インポートは現在の登録内容を置き換えるため、実行前に内容を比べて表示します。

- 「現在」と「ファイル」を並べて、**最終更新の日時**と、**グループ・リンク・ドメインの件数**（増減つき）を表示
- ファイルが現在のデータより古い場合は強い警告を出し、「古い内容で上書きし、それ以降の変更が失われることを確認しました」にチェックするまでインポートできません
- 件数が半分以上減る場合や、日時を読み取れないファイルの場合も理由を表示します
