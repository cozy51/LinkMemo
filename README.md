# LinkMemo - 仕事スタート

仕事で使うWebページをグループに登録し、まとめてタブで開けるWebアプリです。Vercelに静的サイトとしてデプロイして使います（v2.0.0でブラウザー拡張機能から単独のWebアプリに移行しました）。

## 主な機能

- グループ単位、または全グループのリンクをまとめて開く
- グループ／リンクの追加・編集・削除・並べ替え
- 用途別の30種類のグループアイコンと8種類の背景色
- グループとリンク、移動・編集・削除操作を色分け
- グループの折りたたみ状態を保存
- 登録内容のJSONバックアップと復元（インポート前に件数と日時を比較）
- Supabaseによるクラウド同期と、上書き前の内容を残すクラウド履歴
- データはブラウザーのローカルストレージ（`localStorage`）に保存（クラウド同期は任意）
- 画面左上にアプリのバージョンを表示（`web-platform.js` の `LINK_MEMO_APP_VERSION`）

## Vercelへのデプロイ

ビルドは不要です。リポジトリのルートをそのまま静的サイトとして公開します。

1. Vercelで「Add New… → Project」からこのリポジトリをインポートする
2. Framework Preset は「Other」、Build Command・Output Directory は空のまま（ルートを公開）
3. 「Deploy」を押す

`vercel.json` でセキュリティ用のヘッダーを設定し、`.vercelignore` でテスト用スクリプトやPDFを公開対象から外しています。

ローカルで確認する場合は、ルートで簡易サーバーを起動して `http://localhost:8000/` を開きます。

```bash
python3 -m http.server 8000
```

## 使い方

1. デプロイしたURLを開き、ブラウザーのブックマークやスタートページに登録する
2. 「＋ 新しいグループ」と各グループの「＋ リンク追加」で登録する
3. 仕事開始時に「すべてのタブを開く」または各グループの「まとめて開く」を押す

### ポップアップの許可

Webページから複数のタブを一度に開くと、ブラウザーがポップアップとしてブロックします。初回に「ポップアップがブロックされました」と表示されたら、アドレスバー右端のアイコンから **このサイトのポップアップを常に許可** してください。

### 登録できるURL

`http://` または `https://` のWebページを登録できます。拡張機能版で登録した `chrome-extension://`・`chrome://`・`edge://` のリンクもそのまま保持されますが、ブラウザーの制限によりWebページからは開けません。クリックするとURLをクリップボードへコピーするので、アドレスバーに貼り付けて開いてください。

### 拡張機能版からのデータ移行

拡張機能のデータはWebアプリから直接読めません。次のどちらかで移してください。

- **クラウド同期を使っていた場合**：Webアプリで同じ「クラウド設定」を入力してログインすれば、クラウドの内容が読み込まれます
- **使っていない場合**：拡張機能の編集画面で「エクスポート」し、Webアプリの「インポート」で読み込みます

データはブラウザー・ドメインごとに保存されます。別のブラウザーやPCで同じ内容を使うには、クラウド同期を設定してください。

## クラウド同期とバックアップ（Supabase）

TodoMemo・Prompt Memoと同じ仕組みで、Supabaseを正本、ブラウザーの `localStorage` をその手元のコピーとして扱います。ログインしていれば、追加・編集・削除のたびに自動でクラウドへ保存され、**上書きされる直前の内容は必ず履歴として残ります**。

### 準備

1. Supabaseでストレージのバケット（既定は TodoMemo と同じ `todo-backups`）を用意し、ログインするユーザーが自分のフォルダー（`{ユーザーID}/`）を読み書きできるポリシーを設定する
2. 画面右上の「クラウド設定」に、プロジェクトURL・anonキー・バケット名を入力して保存する
3. 「ログイン」にSupabaseのメールアドレスとパスワードを入力する

### 保存される場所

TodoMemoと同じバケットを共有できるよう、ファイル名にアプリ名が入ります。

- `{ユーザーID}/LinkMemo-latest.json`：クラウド上の最新の全グループ・全リンク
- `{ユーザーID}/LinkMemo-history/`：上書きされる直前の内容（履歴）

### 履歴の残り方と戻し方

- クラウドが上書きされるたびに、上書き前の内容を1件ずつ保管します
- 直近30件はすべて残し、それより古いものは1日1件で最大30日分を残します
- 「クラウド履歴」から、件数と日時を見て任意の時点に戻せます
- 戻す操作も「新しい版」として記録するため、他のPCも安全に追従します

### 古いデータで上書きしないためのしくみ

- クラウドの版（リビジョン）を基準に更新するため、古いPCが新しい内容を黙って上書きすることはありません
- 食い違いが起きたときは、**クラウドとこのPCの「最終更新」「グループ数」「リンク数」「ドメイン数」を並べて比較**し、増減付きで表示します
- このPCの内容がクラウドより**古い**、または**件数が大きく減る**場合は強い警告を出し、確認のチェックを入れるまで「このPCの内容でクラウドを上書き」を押せません
- リンクが半分以上減る変更や、リンクが1件も無くなる変更（ブラウザーデータの削除や誤操作など）は、確認するまでクラウドへ反映しません
- 選ばなかった方の内容もクラウド履歴へ退避するため、どちらを選んでも元に戻せます
- ログアウト中の変更はこのPCだけに保存され、次回ログイン時に上記の手順で照合されます

### インポート前の確認

全件インポートは現在の登録内容を置き換えるため、実行前に内容を比べて表示します。

- 「現在」と「ファイル」を並べて、**最終更新の日時**と、**グループ・リンク・ドメインの件数**（増減つき）を表示
- ファイルが現在のデータより古い場合は強い警告を出し、「古い内容で上書きし、それ以降の変更が失われることを確認しました」にチェックするまでインポートできません
- 件数が半分以上減る場合や、日時を読み取れないファイルの場合も理由を表示します
