# LinkMemo - Chrome / Edge 仕事スタート

仕事で使うWebページをグループに登録し、Google ChromeまたはMicrosoft Edgeのツールバーからまとめてタブで開ける拡張機能です。同じ拡張機能フォルダーを両方のブラウザーで利用できます。

## 主な機能

- グループ単位、または全グループのリンクをまとめて開く
- 現在表示中のタブをポップアップから素早く登録
- クイック追加で前回選んだグループを記憶
- グループ／リンクの追加・編集・削除・並べ替え
- 用途別の30種類のグループアイコンと8種類の背景色
- 編集画面でグループとリンク、移動・編集・削除操作を色分け
- グループの折りたたみ状態を保存
- 登録内容のJSONバックアップと復元
- データはブラウザー内のローカルストレージに保存

## Google Chromeへのインストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダー（`LinkMemo`）を選択する
5. ツールバーの拡張機能メニューからLinkMemoを固定する

## Microsoft Edgeへのインストール

1. Edgeで `edge://extensions/` を開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押す
4. このフォルダー（`LinkMemo`）を選択する
5. ツールバーの拡張機能メニューからLinkMemoをピン留めする

## ブラウザー間のデータについて

登録内容は各ブラウザーのローカルストレージに保存されます。ChromeとEdgeの登録内容は自動同期されないため、同じ内容を使う場合は編集画面の「エクスポート」でバックアップし、もう一方のブラウザーで「インポート」してください。

## 使い方

1. LinkMemoのアイコンを押し、右上の歯車から編集画面を開く
2. グループとリンクを登録する
3. 仕事開始時に「すべてのタブを開く」または各グループの「まとめて開く」を押す

`http://` または `https://` のWebページを登録できます。登録データは外部サーバーへ送信されません。

拡張機能を読み込む前に見た目だけ確認したい場合は、`popup.html` または `options.html` をブラウザーで直接開くとサンプルデータ付きのプレビューになります。拡張機能として動作するときは、プレビュー用データは使用されません。
